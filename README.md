# ThreatX

ML-Based Cybersecurity Threat Detection and Network Intrusion Monitoring System.

## Overview

ThreatX is a machine-learning-based cybersecurity system designed to
detect known network threats and identify unusual network behavior.

## Planned Features

- Network traffic analysis
- ML-based threat classification
- Anomaly detection
- Threat severity analysis
- Security alerts
- Threat analytics dashboard
- Explainable ML
- Real-time traffic simulation
- Security reports

## Technology Stack

- Python
- FastAPI
- Scikit-learn
- PostgreSQL
- HTML
- CSS
- JavaScript
- Chart.js
